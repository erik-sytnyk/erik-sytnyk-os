# 🪞 Спецификация: Shadow Mirror & Периметр Внимания (Orbios 3.x)

## 1. Двухконтурная Анатомия Внимания

Концепт Shadow Mirror в FOUNDER OS разделен на два канонических уровня: внутренний (психобиометрический контур саморегуляции) и внешний (инфраструктурный шлюз фильтрации внимания).

```
|  ВНЕШНИЙ МИР (Внешний хаос, линейные метрики, скептицизм)        |
|                                                                   |
|     =======> [ ВНЕШНИЙ ШУМ / ИСТОЧНИКИ ШУМА ] =======>            |
|                                                                   |
|   =============================================================   |
|  |  SHADOW MIRROR PERIMETER (Слой 2 FOUNDER OS: Броня внимания)|  |
|  |  (Внутри: Founder, Serv Nodes с жесткими обязательствами)   |  |
|  |                                                             |  |
|  |   =======================================================   |  |
|  |  |  SHADOW MIRROR (Tier E: Приватный Психо-Якорь)        |  |  |
|  |  |  (Биометрия в /health/, Внутренний диалог с ИИ)       |  |  |
|  |   =======================================================   |  |
|   =============================================================   |
```

### 🧠 Контур А: Ядро Shadow Mirror (Саморегуляция)

*   **Тир доступа:** Tier E (Абсолютный приватный контур Фаундера — репозиторий `erik-sytnyk-os`).
*   **Локация:** Данные биометрии и здоровья собираются в `modules/founder-private/health/`.
*   **Суть:** Инструмент цифрового отражения внутреннего состояния Фаундера для анализа деструктивных паттернов и удержания Track A (FVE).
*   **Guardrail (Канон R6):** Контур существует исключительно для саморегуляции. В соответствии с правилом R6 (No Founder absorption), данные этого контура изолированы от прямого влияния на операционные метрики Serv Nodes.

### 🛡️ Контур Б: Shadow Mirror Perimeter (Фильтр Внимания)

*   **Архитектурный статус:** Слой №2 глобального Нода FOUNDER OS (`context/manifest.md` Amendment A028).
*   **Суть:** Жесткий входящий шлюз вокруг ментального ресурса Фаундера.
*   **Операционная логика:**
    *   **Внутри периметра:** Прямая синхронизация, доверие, прозрачность. Здесь находятся Фаундер и верифицированные Serv Nodes, связанные квантифицируемыми обязательствами (фиксированные компенсации, миссии, скоуп из `sops/task_management.md` и personnel-файлов).
    *   **Снаружи периметра:** Внешний мир. Любое взаимодействие идет исключительно через каскад фильтров: ИИ-агенты, R5-роутинг, пре-пуш хуки и защитный firewall правил A025/OD-038.

## ☣️ Структура Изоляции Внешних Угроз (Контур Изоляции)

Для защиты Track A (FVE) система координирует три независимых инструмента изоляции внешнего шума и деструктивных факторов:

### 1. Социальный контур: Трек LEGACY (Канон A009)

*   **Объект:** Изоляция Фаундера от токсичной социальной среды (деструктивные контакты из прошлых итераций Orbios 1.x / 2.x).
*   **Учет:** Попытки деструктивного вмешательства фиксируются как `Breach Count` на главном дашборде жизненных метрик (`manifest.md`, OD-024). Любое решение о ручном бане или активации процедур A009 принимается **исключительно Фаундером (Founder Gate)**.

### 2. Организационный контур: Токсичный Капитал (Канон A023)

*   **Объект:** Защита структуры компании от деструктивного давления внешнего капитала.
*   **Догма:** Внедряется класс UA-02 (Токсичные инвесторы). Действует жесткое правило: *Investor is NEVER a Founder/Partner/Principal*. Вокруг их активности выстраиваются изолированные шлюзы коммуникации.

### 3. Шлюз Внешнего Шума: SOP `external_noise_filter.md` (Канон OD-071)

*   **Статус:** Ратифицирован 3 июня 2026 г. (Pillar 1).
*   **Механика:** Линейный скептицизм, непрошенные оценки бизнес-решений или метрик снаружи Периметра Внимания перехватываются ИИ-агентами на дальних подступах и автоматически сбрасываются в изолированные дампы шума: `modules/founder-private/noise-dumps/`. Они не доходят до глаз Фаундера и не отвлекают его от архитектурной работы.

## 🎯 Фундаментальный принцип Orbios 3.x

> **Эмпатия внутри периметра — Протокол снаружи.** Любой внешний раздражитель маргинализируется шлюзом OD-071. Система изолирует шум, удерживая фокус Фаундера на стратегическом исполнении.
