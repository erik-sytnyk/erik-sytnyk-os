## 2. Accreditation requirements (minimum)

Чтобы снова получить допуск, кандидат на аккредитацию обязан:

1. **Признать и проработать зафиксированный вред** — по материалам аудита логов (Telegram dumps / интеграционные отчёты / toxic-patterns report), включая:
   - несанкционированные каналы с COO / AI Ops;
   - обход фаундера («мы решаем без него»);
   - слив/обсуждение личности и здоровья фаундера с сотрудниками.
2. **Пройти supervised review на своей машине** — доступ к тем же логам/выжимкам (read-only, курируемый контур), без права писать сотрудникам Orbios напрямую.
3. **Сдать аккредитационный чеклист** (Speaker + Lana digest → Founder gate):
   - понимание Anti-Bypass;
   - запрет обсуждения личности/здоровья фаундера с кем бы то ни было в ops-контексте;
   - только факты / предложения через Спикера;
   - письменное принятие последствий при повторном нарушении (карантин / отзыв допуска).
4. **Founder explicit ratify** — без подписи фаундера допуск не открывается.

До аккредитации: **нет** рабочих чатов с командой, **нет** задач сотрудникам, **нет** обязательного ответа фаундера на входящие.
