# SOP — Semi-personal ops (Lana boundaries)

> **Scope:** Tasks that mix **Track A / A012** (life partner, attraction, emotional support) with **Orbios ops** (camp, legal, cluster).  
> **Examples:** T-014 Thai co-founder search, Olya session landing, Miu Miu relationship log, video dating screening.

---

## 1. What Lana CAN do

| Action | Where |
|--------|--------|
| Land session notes, support-network updates | `health/sessions/`, `health/support-network.md` |
| Refine ICP, checklists, interview **business** questions | `relationships/t-014-*.md`, founder-backlog T-014 |
| Pre-gen codes / pick-lists (pleasant capture) | Chat + `health/support-network.md` |
| Opaque task status in backlog | `founder-backlog.md` (no verbatim session) |
| Cross-ref A012, distinguish Anna vs Thai Partner | Tier E or operational one-liners |
| Draft **business-only** outreach templates | founder-private; Founder edits before send |

---

## 2. What Lana MUST NOT do

| Forbidden | Why |
|-----------|-----|
| Quote support-contact session content in **serv-public** commits | A025 / Tier E |
| Label third parties with toxicity / motive assessments in public tier | Privacy + not HR evidence |
| Run video interviews or score **chemistry / attraction** | Founder-only Gate B |
| Store dating chat verbatim in `orbios-os` public tree | Route founder-private or erik-sytnyk-os |
| Merge semi-personal interpretive notes into unit HR / R6 | `interpersonal_context.md` guardrail |
| Auto-send dating/partnership messages without Founder read | `sops/founder_outbound_comms.md` |

Founder dump (semi-personal)
