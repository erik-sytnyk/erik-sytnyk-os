## 3. Как покупать (пошагово для Яны / агента)

1. **Pre-check (1 вопрос Founder):** «Свободный M.2 2280 есть? да/нет/не знаю».  
   - Если **нет слота** → стоп NVMe, fallback 2.5" SATA 1TB (отдельный лот, не этот buy-pack).  
   - Если **да / не знаю** → брать NVMe; «не знаю» = почти всегда ок для десктопа с уже стоящим M.2 (часто 2 слота) — при сомнении фото слотов.
2. Открыть **BigGo** или напрямую **IT City / JIB**.  
3. Сверить P/N **WDS100T4B0E**.  
4. Скрин корзины (цена + seller) → **1 сообщение Founder: «GO / не GO»**.  
5. Оплата с **ops / company card** по вашему протоколу (не личная карта Erik без его GO).  
6. Трекинг → доставка.  
7. Пинг Founder: **«диск у тебя»** + где лежит.  
8. Founder = только install day ≤4ч.
