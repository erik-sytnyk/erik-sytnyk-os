## How to log a violation

1. Файл `violations/V-00N-YYYY-MM-DD-<slug>.md`  
2. Строка в таблице выше  
3. Обновить статус `P-00N` (BREACHED / PARTIAL) если нужно  
4. При серьёзном breach — кросс-ссылка в `evidence/E-00N` и perimeter accreditation
