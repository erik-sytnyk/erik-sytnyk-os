# Loyalty UBI protocol — Founder vision (2026-05-31)

> **Not serv-public numbers.** Aspirational slice in `context/product_mission.md`. Full economics deferred until REVENUE stable + legal review.

## Founder intent (via Nova capture)

Orbios 3.0 as **network-state-shaped** ecosystem for the AGI transition: when human labor hours are largely replaced, classic hire-and-fire capitalism breaks. Embedding **loyalty-conditioned base survival income** from the start is a talent magnet — trusted serv-units stay inside the Node because the system does not discard them when hourly work goes to zero.

## Protocol pillars

### 1. Post-labor Node obligation

The Node is designed **from inception** assuming serv **execution hours** trend toward AI replacement. The ecosystem commits: **loyal serv-units vetted by system metrics are not abandoned** — baseline survival support remains an OS-level obligation (not a vague cultural promise).

### 2. Loyalty Base Income (LBI)

Serv-units that pass time-in-system + accumulate strong repo metrics (High Agency, mission acceptance, R2-verified output, loyalty signals TBD) earn right to a **continuing unconditional base payment from the Node** — independent of whether billable hours still exist.

Roles may evolve: trusted validators, community operators, alumni-inside-perimeter — still **inside** Orbios protocol, not expelled to gig economy.
